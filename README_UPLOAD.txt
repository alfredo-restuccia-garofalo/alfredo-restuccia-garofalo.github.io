Update instructions for GitHub Pages

1. Open your repository: alfredo-restuccia-garofalo.github.io
2. Click Add file -> Upload files.
3. Upload ALL files and folders contained in this package:
   - index.html
   - research.html
   - publications.html
   - teaching-aesei.html
   - editorial.html
   - links.html
   - assets/ folder
4. Commit changes with the message: Multi-page academic website update
5. Wait 1-3 minutes and refresh the website:
   https://alfredo-restuccia-garofalo.github.io/

If the old version remains visible, press Ctrl + F5 in the browser.
